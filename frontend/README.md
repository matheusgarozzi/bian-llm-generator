# Frontend — Gerador BIAN-LLM

Interface (CSR) do Gerador de Aplicações Guiado por Arquitetura de Referência utilizando LLM.

## Stack

- React 19 + TypeScript
- Vite
- oxlint (lint) + Prettier (formatação)

## Rodando localmente

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run lint` — lint (oxlint)
- `npm run format` — formata o código (Prettier)
- `npm run preview` — pré-visualiza o build de produção
